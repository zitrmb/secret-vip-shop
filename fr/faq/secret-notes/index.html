Secret Notes

Réponses courtes aux questions fréquentes.

À quoi sert Secret Notes ?

Secret Notes affiche une note de notes.secret.vip par projet, directement dans ton logiciel de musique. Tu peux aussi l'y modifier. Ton audio reste inchangé.

De quoi ai-je besoin pour Secret Notes ?

Sur Mac, il faut macOS 12 ou ultérieur, Apple Silicon ou Intel et un logiciel de musique compatible VST3, AU ou CLAP. Le paquet Windows contient des plugins VST3 et CLAP 64 bits ; l'interface nécessite Microsoft Edge WebView2. Un compte notes.secret.vip est nécessaire pour se connecter. La version minimale de Windows n'est pas encore confirmée pour ce paquet.

Pourquoi Secret Notes ne choisit-il pas la note tout seul ?

La note suit le nom de ton projet une fois celui-ci enregistré. Si ton logiciel ne fournit pas de nom, choisis la note toi-même via le menu d'engrenage ou en cliquant dans le champ vide. C'est le cas, par exemple, dans Logic quand le plugin AU fonctionne dans un processus séparé.

Ai-je besoin d'un achat, d'une clé de licence ou d'un compte ?

Secret Notes est gratuit. Aucun achat ni clé de licence n'est nécessaire pour le télécharger. Un compte notes.secret.vip est nécessaire pour synchroniser tes notes. Téléchargement : https://plugins.secret.vip/download/

Comment installer Secret Notes sur Mac ou Windows ?

Mac : ouvre le paquet d'installation téléchargé et suis les étapes. Windows : décompresse le téléchargement. Copie le dossier complet VST3\SecretNotes.vst3 dans C:\Program Files\Common Files\VST3 et le fichier CLAP\SecretNotes.clap dans C:\Program Files\Common Files\CLAP. Redémarre ton logiciel de musique et cherche Secret Notes. Garde les protections de sécurité activées. Téléchargement : https://plugins.secret.vip/download/

Comment mettre à jour Secret Notes et obtenir de l'aide ?

Télécharge les nouveaux paquets sur notre page et installe celui de ton ordinateur. Pour obtenir de l'aide, indique ton système, ton logiciel de musique et la version utilisée. N'envoie ni mots de passe, ni données de connexion, ni notes privées. Les questions de clés de licence achetées concernent les plugins payants. Téléchargement : https://plugins.secret.vip/download/

Secret Notes est-il une version d'essai ?

Non. Secret Notes est gratuit et n'est pas un essai limité dans le temps. Aucun achat ni clé de licence n'est nécessaire.

Puis-je utiliser Secret Notes sur un autre ordinateur ?

Oui. Secret Notes ne nécessite pas d'activation. Installe-le sur l'autre ordinateur et connecte-toi avec ton compte notes.secret.vip pour y retrouver tes notes. La limite de deux ordinateurs concerne uniquement les licences achetées.

Secret Notes fonctionne-t-il sans Internet ?

Internet est nécessaire pour se connecter. Si la connexion coupe ensuite, continue d'écrire : tes modifications sont conservées sur ton ordinateur et synchronisées au retour de la connexion. Il n'y a pas de période hors ligne, car Secret Notes ne nécessite pas de licence achetée.

Comment désinstaller Secret Notes ?

Ferme ton logiciel de musique et supprime les fichiers du plugin SecretNotes. Mac : dans le Finder, ouvre ton disque, puis Bibliothèque → Audio → Plug-Ins ; les fichiers sont dans VST3, Components et CLAP. Windows : dans C:\Program Files\Common Files\VST3 et C:\Program Files\Common Files\CLAP. Les notes de ton compte sont conservées.

Quelle version de Secret Notes est disponible ?

Au 4 novembre 2026, Secret Notes est proposé en version 1.2.1 sur Mac et 1.2.1 sur Windows. Il s'agit de la version du téléchargement proposé ; celle installée sur ton ordinateur peut être différente. Dernier téléchargement disponible : https://plugins.secret.vip/download/.
