Privacy

Our full privacy policy is on secret.vip/datenschutz. This page adds what the plugins and this shop do.

License check

When you start the trial or activate, the plugin connects to our license server license.secret.vip (server in Germany, Hetzner). It sends an anonymous computer ID (a one-way hash), the license key, the time, the computer type (e.g. "MacIntel") and - only if you enter it - your email address. Purpose: fulfilling the contract (Art. 6 (1) b GDPR) and preventing misuse (Art. 6 (1) f GDPR). Stored as long as the license exists, then deleted after the legal retention periods.

Purchase via Paddle

Order, payment and invoice are handled by Paddle.com Market Ltd (London, UK) as reseller. Paddle sends us name, email address and order number so we can issue your license key. Paddle privacy: paddle.com/legal/privacy.

License key email

We send license keys by email via Brevo (Sendinblue GmbH, Berlin). Processed: name and email address. The same applies when you ask for your key again on the lost key page.

Update notice

At most every 12 hours the plugin reads a public version list from GitHub Pages (GitHub Inc., USA). Only the normal IP connection is made, no ID is sent.

This website

This website is hosted on GitHub Pages (GitHub Inc., USA), which processes your IP address to deliver the page. No cookies, no tracking. The checkout window is loaded from Paddle only when you press Buy.

Deutsch

Lizenzprüfung: Beim Start der Testzeit und bei der Aktivierung verbindet sich das Plugin mit unserem Lizenzserver license.secret.vip (Server in Deutschland, Hetzner). Verarbeitet werden: eine anonyme Rechner-Kennung (nicht umkehrbarer Hashwert), Lizenzschlüssel, Zeitpunkt, Rechnertyp und optional die E-Mail-Adresse. Zweck: Vertragserfüllung (Art. 6 Abs. 1 lit. b DSGVO) und Schutz vor Missbrauch (Art. 6 Abs. 1 lit. f). Speicherdauer: solange die Lizenz besteht, danach Löschung nach gesetzlichen Fristen.

Kauf über Paddle: Bestellung, Zahlung und Rechnung wickelt Paddle.com Market Ltd (London, UK) als Händler ab und übermittelt uns Name, E-Mail-Adresse und Bestellnummer für den Lizenzschlüssel.

Schlüssel-Mail: Versand über Brevo (Sendinblue GmbH, Berlin); verarbeitet werden Name und E-Mail-Adresse.

Update-Hinweis: Höchstens alle 12 Stunden liest das Plugin eine öffentliche Versionsliste bei GitHub Pages (GitHub Inc., USA); keine Kennung wird übertragen.

Diese Website: gehostet bei GitHub Pages (GitHub Inc., USA), keine Cookies, kein Tracking.
