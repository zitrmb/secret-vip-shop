5. Lizenzserver

Unser Lizenzserver license.secret.vip läuft bei Hetzner Online GmbH, Industriestr. 25, 91710 Gunzenhausen, in Deutschland (Auftragsverarbeitung, Art. 28 DSGVO). Er speichert nur, was für die Lizenz nötig ist:

  • Lizenz: Name, E-Mail-Adresse, Produkt, Bestellnummer, Zeitpunkt; den Lizenzschlüssel nur als nicht umkehrbaren Hashwert plus kurzen Erkennungsteil.
  • Aktivierungen: pseudonyme Rechnerkennung (nicht umkehrbarer Hashwert), Rechnertyp (z. B. „MacIntel“), erste und letzte Prüfung. Die E-Mail-Adresse nur, wenn Sie sie bei der Aktivierung eingeben.
  • Testversionen (sofern angeboten): pseudonyme Rechnerkennung und Laufzeit, damit eine Testzeit nur einmal beginnt.

IP-Adressen speichert der Lizenzserver nicht, und er schreibt keine Zugriffsprotokolle mit IP-Adressen. Zweck: Vertragserfüllung (Art. 6 Abs. 1 lit. b DSGVO) und Schutz vor Missbrauch der Lizenzschlüssel (Art. 6 Abs. 1 lit. f DSGVO). Speicherdauer: solange die Lizenz besteht, weil Sie sie zeitlich unbegrenzt nutzen dürfen. Auf Ihren Wunsch löschen wir Name, E-Mail-Adresse und Aktivierungen früher; der Schlüssel wird dann gesperrt. Tägliche Sicherungskopien der Datenbank liegen auf demselben Server und werden nach 30 Tagen gelöscht.

5. License server

Our license server license.secret.vip runs at Hetzner Online GmbH, Industriestr. 25, 91710 Gunzenhausen, in Germany (processor, Art. 28 GDPR). It only stores what the license needs:

  • License: name, email address, product, order number, time; the license key only as a one-way hash plus a short recognition part.
  • Activations: pseudonymous computer ID (one-way hash), computer type (e.g. "MacIntel"), first and last check. The email address only if you enter it when activating.
  • Trial versions (where offered): pseudonymous computer ID and trial period, so that a trial starts only once.
  • Event log: time, type (e.g. activation, deactivation), license and computer ID.

The license server does not store IP addresses and writes no access logs with IP addresses. Purpose: performing the contract (Art. 6(1)(b) GDPR) and protecting license keys against misuse (Art. 6(1)(f) GDPR). Retention: as long as the license exists, because you may use it without time limit. On request we delete name, email address and activations earlier; the key is then blocked. Daily backups of the database are kept on the same server and deleted after 30 days.
